# 🧩 Unit Tests — Лабораторна робота №1

## 🎯 Мета тестування
Перевірити коректність роботи класу **`StudentManager`**, що реалізує:
- додавання та видалення студентів;
- пошук за ім’ям;
- розрахунок середнього балу;
- визначення найкращого та найгіршого студента;
- обробку некоректних даних (нульові або від’ємні значення, дублікати тощо).

---

## ⚙️ Технології
- **Мова:** C++ (C++17)  
- **Бібліотека тестування:** стандартні засоби (`assert`)  
- **Система збірки:** CMake  
- **IDE:** CLion  

---

## 🧠 Структура тестів
Файл **`test_student_manager.cpp`** містить 15 окремих юніт-тестів, які покривають основні функції класу.

| №  | Назва тесту | Опис перевірки |
|----|--------------|----------------|
| 1  | Add student  | Перевірка, що студент успішно додається |
| 2  | Add duplicate | Перевірка обробки дубліката імені |
| 3  | Remove student | Тест видалення наявного студента |
| 4  | Remove non-existing | Видалення неіснуючого студента |
| 5  | Find best student | Визначення студента з найвищим балом |
| 6  | Find worst student | Визначення найнижчого балу |
| 7  | Average grade | Обчислення середнього балу |
| 8  | Get grade by name | Пошук оцінки за ім’ям |
| 9  | Get grade invalid name | Обробка неіснуючого імені |
| 10 | Invalid name | Перевірка додавання з порожнім іменем |
| 11 | Invalid age | Некоректний вік студента |
| 12 | Invalid grade | Некоректна оцінка (>100 або <0) |
| 13 | Clear list | Перевірка очищення списку |
| 14 | Count students | Перевірка підрахунку студентів |
| 15 | Stability test | Фінальний тест стабільності |
