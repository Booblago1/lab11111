# 🧪 Лабораторна робота №1 — Юніт-тестування

## 🎯 Мета роботи
Закріпити навички роботи з системою контролю версій **Git** та навчитися створювати і виконувати **юніт-тести** для перевірки коректності програмного коду на мові **C++**.

---

## 🧩 Завдання
1. Розробити клас **`StudentManager`**, який дозволяє:
   - додавати, видаляти та шукати студентів;
   - обчислювати середній бал;
   - знаходити студента з найвищим і найнижчим балом.
2. Реалізувати обробку некоректних даних (викидання винятків).
3. Створити не менше **15 юніт-тестів**, які перевіряють роботу кожного методу.
4. Виконати тестування та зафіксувати результати.
5. Розмістити код у **GitHub** з оформленням **Pull Request** для перевірки.

---

## ⚙️ Використані технології
- **Мова програмування:** C++ (C++17)  
- **Середовище розробки:** CLion  
- **Система збірки:** CMake  
- **Система контролю версій:** Git + GitHub

## 🧠 Опис процесу написання юніт-тестів
Після реалізації класу `StudentManager` було створено файл `test_student_manager.cpp`, де реалізовано **15 тестів** із використанням `assert()`.  
Кожен тест перевіряє окрему функціональність:
- додавання та видалення студентів;
- пошук за ім’ям;
- розрахунок середнього балу;
- визначення кращого та гіршого студента;
- обробку помилкових вхідних даних.  

Усі тести виконано успішно (**exit code 0**), що підтверджує правильність реалізації програми.
